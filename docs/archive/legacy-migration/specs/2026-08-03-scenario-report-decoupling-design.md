# 模拟对话与报告生成解耦设计

> 历史设计记录，不是当前运行说明。当前入口见[项目 README](../../../../README.md)与[开发交接说明](../../../AGENT-HANDOFF.md)。

## 目标

最后一轮只等待顾客回复，报告在顾客回复展示完成后于当前对话页异步生成。报告成功持久化后才提示学员查看。

## 交互

- 最后一轮顾客回复完成后自动进入“分析对话 → 生成评分与建议 → 保存报告”。
- 学员提前结束时使用同一套当前页生成流程，并以 `finishing=1` 标记刷新恢复。
- 生成期间锁定输入；成功后显示“报告已生成”和查看按钮；失败后保留对话并提供手动重试。
- 阶段进度条只表示处理阶段，不伪造精确百分比。

## 服务边界

- `sendMessage()` 不再在最大轮次隐式评测，会话保持 active。
- 报告 SSE 增加阶段事件，并保证 completed 会话落库后才发送最终完成事件。
- 不新增数据库实体或外部依赖；已有报告页保留兼容路径。

## 验收

- 最后一轮顾客回复耗时不受报告评测 180 秒超时影响。
- 自然结束、提前结束、刷新恢复、成功查看和失败重试均有自动化覆盖。
