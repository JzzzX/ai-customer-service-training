# AI 培训智能客服 Roadmap

最后更新：2026-08-01

## 当前结论

项目已具备“技术可用 MVP”形态：学员端、管理员端、专题练习、情景实战、角色登录、Neon 持久化和 Vercel 部署链路均已实现。

正式培训内容仍有一道人工门禁：40 道可追溯正式题当前为 0/40 审核，尚未发布正式题组。350 道专题题可以支持日常练习，但不能替代正式题内容审批。

线上真实 AI 代码链路已接入并有本地 Provider 测试；当前 Vercel Production 冒烟返回 Vercel AI Gateway 账单未开通（403），需要项目所有者在 Vercel AI 设置中完成可用账单配置后再次复验。

## 版本状态

| 范围 | 状态 | 说明 |
|---|---|---|
| 现代化前端 UI | 已完成 | 学员端、管理员端、登录、测验、情景实战统一视觉语言，并覆盖移动端布局 |
| 知识库编译 | 已完成 | Markdown、Excel、MM 适配器、版本化知识包、来源追溯和冲突隔离 |
| 专题练习题 | 技术验收通过 | 5 个专题、350 题；每次练习 10 题，题型和难度按配额抽取 |
| 正式知识小测 | 内容验收中 | 40 道题仍需知识负责人逐题审核并发布 |
| AI 模拟对话 | 代码验收通过，线上待复验 | 完整上下文、重复回复重试、空回复保护、风险提示和报告生成已实现 |
| 认证与权限 | 已完成 | 学员/管理员 Credentials 登录、受保护路由和越权拦截 |
| 生产部署 | 已部署 | Vercel + Neon；生产真实 AI 受 Gateway 账单配置阻塞 |

## 下一步优先级

### P0：解除交付阻塞

1. Vercel 项目所有者完成 AI Gateway 账单配置，重新执行 `pnpm test:e2e:live`。
2. 知识负责人完成 40/40 正式题审核、修订争议题并发布正式题组。
3. 运行 `pnpm production:verify:data --formal`，保存正式内容验收证据。

### P1：试用运营完善

1. 为试用学员建立账号发放与回收流程。
2. 收集 AI 对话低置信度报告，人工抽查模型评分与风险识别。
3. 记录 Vercel AI Gateway 用量、成本、失败率和平均响应时间。

### P2：企业化迭代

1. 接入飞书身份与企业用户映射。
2. 将知识负责人、审核人、知识库管理员和运营责任纳入权限模型。
3. 评估企业知识引擎适配器；不在当前 MVP 中引入开放式 RAG、知识上传后台或多模态处理。

## 当前不纳入 MVP

- 飞书身份、飞书实时同步和企业知识引擎正式接入。
- 图片 OCR、多模态问答和开放式 RAG。
- 正式考试防作弊、题目一次性发放和认证成绩体系。
- 积分、排行榜、签到和复杂学习门户。
