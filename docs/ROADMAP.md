- 2026-07-29：取消飞书Webhook实时同步，改为本地离线解析和不可变知识版本发布。
- 2026-07-29：首版只处理文字；图片、OCR和多模态延期。
- 2026-07-29：不建设知识上传后台，不使用向量库或开放式RAG。
- 2026-07-29：GitHub私有仓库，主要开发直接进入 `main`；高风险实验使用短期 `feature/*` 分支。
- 2026-07-29：真实源文件不进入Git，规范化知识由本机直接写入Neon。
- 2026-07-29：真实AI接口暂缓，`v0.1.0` 使用明确标识的Mock Provider。
- 2026-07-29：企业知识引擎当前不可稳定接入，MVP恢复本地离线知识方案；后续可将
  企业知识引擎作为独立适配器评估，不阻塞MVP。
- 2026-07-29：当前真实资料集为6个Markdown和2个Excel文件；MM适配器保留并测试，
  但不把不存在的MM文件计入当前资料覆盖门禁。
- 2026-07-29：MVP使用Auth.js Credentials和Neon用户表作为临时身份入口，不引入
  Supabase；后续接入飞书账号时只替换认证Provider与用户映射层，既有角色、训练记录和
  业务数据模型保持不变。
- 2026-07-29：知识题可从有效知识版本辅助生成，但必须先进入草稿态；管理员审核后才可
  发布给学员，避免未经确认的干扰项进入正式训练。
